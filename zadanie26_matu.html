1) Cel stosowania szablonów HTML 4.01 Transitional

Szablon HTML 4.01 Transitional jest bardziej łagodnym zbiorem zasad i potrafi wybaczyć pewne rzeczy w porównaniu do wersji Strict.

2) Opis

  • 'Strict' - Strict składa się z bardzo rygorystycznych reguł co można a czego nie można robić w danym dokumencie HTML
  • 'Transitional' - Transitional jest bardziej łagodnym zbiorem zasad i potrafi wybaczyć pewne rzeczy
  • 'Frame Set' - Frame Set prawie na wymarciu w obecnych czasach

3) Przykłady szablonów HTML 4.01 Transitional

Przykład deklaracji:

<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" 
"http://www.w3.org/TR/html4/loose.dtd">

4) Wartości domyślne

Jeśli nie podamy żadnej z wersji DTD, jako domyślna najprawdopodobniej zostanie przyjęta Transitional DTD (w MSIE), ale sposób ten absolutnie nie jest zalecany!
