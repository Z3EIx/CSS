Rodzaje Selektrorów

  1. Selektor prosty (selektor typu):
    • Wybiera elementy na podstawie nazwy znacznika HTML.
    • Przykład: p { color: red; } (wszystkie akapity będą czerwone).
  2. Selektor uniwersalny:
    • Wybiera wszystkie elementy na stronie.
    • Przykład: * { margin: 0; padding: 0; } (zeruje marginesy i paddingi dla wszystkich elementów).
  3. Selektor potomka:
    • Wybiera elementy, które są potomkami innego elementu.
    • Przykład: div p { color: purple; } (wszystkie akapity wewnątrz div będą fioletowe).
  4. Selektor dziecka:
    • Wybiera elementy, które są bezpośrednimi dziećmi innego elementu.
    • Przykład: div > p { color: orange; } (tylko akapity bezpośrednio wewnątrz div będą pomarańczowe).
  5. Selektor braci:
    • Wybiera elementy, które są siostrzanymi elementami (braćmi) innego elementu.
    • Przykład: h1 ~ p { color: pink; } (wszystkie akapity będące rodzeństwem h1 będą różowe).
  6. Selektor atrybutu:
    • a) Prosty selektor atrybutu:
      • Wybiera elementy na podstawie obecności atrybutu.
      • Przykład: a[target] { color: brown; } (wszystkie linki z atrybutem target będą brązowe).
    • b) Selektor atrybutu o określonej wartości:
      • Wybiera elementy, których atrybut ma dokładnie określoną wartość.
      • Przykład: a[href="https://example.com"] { color: teal; } (linki z dokładnym adresem https://example.com będą turkusowe).
    • c) Selektor atrybutu zawierający określony wyraz:
      • Wybiera elementy, których atrybut zawiera określony wyraz.
      • Przykład: a[href*="example"] { color: navy; } (linki zawierające w adresie słowo "example" będą granatowe).
  7. Selektory specjalne:
    • a) Selektor klasy:
      • Wybiera elementy na podstawie wartości atrybutu class.
      • Przykład: .klasa { color: blue; } (wszystkie elementy z klasą klasa będą niebieskie).
    • b) Pseudoklasy:
      • Wybiera elementy w określonym stanie.
      • Przykład: a:hover { color: yellow; } (linki zmienią kolor na żółty po najechaniu myszką).
    • c) Selektor pseudoelementów:
      • - Pierwsza linia:
        • Wybiera pierwszą linię tekstu w elemencie.
        • Przykład: p::first-line { color: gray; } (pierwsza linia akapitu będzie szara).
      • - Pierwsza litera:
        • Wybiera pierwszą literę tekstu w elemencie.
        • Przykład: p::first-letter { font-size: 2em; } (pierwsza litera akapitu będzie większa).
