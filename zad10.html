Budowa Selektora

  1. Dwie części selektora: Selektor składa się z znacznika (np. p) oraz deklaracji (np. { color: red; }).
  2. Znaczenie nawiasów klamrowych {...}: Nawiasy klamrowe otaczają deklaracje, które określają style dla danego selektora. Przykład: { color: red; }.
  3. Cechy Selektora: Cechą selektora jest właściwość CSS, np. color, która określa, jaki aspekt stylu jest modyfikowany.
  4. Opisz Wartości: Wartość przypisana do cechy określa konkretny styl, np. red dla cechy color oznacza, że tekst będzie czerwony.
  5. Kiedy stosujemy znak średnika (;), kiedy nie jest konieczny: Znak średnika stosujemy po każdej deklaracji w ramach jednego zestawu nawiasów klamrowych, aby oddzielić poszczególne deklaracje. Nie jest konieczny po ostatniej deklaracji w zestawie, ale jest zalecany dla spójności i łatwiejszego dodawania kolejnych deklaracji.
