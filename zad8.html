Wewnętrzny arkusz stylów:

  1. Gdzie jest wstawiany?

    2. Wstawia się zawsze w części nagłówkowej dokumentu (pomiędzy znacznikami <.head>).

  2. Składnia teoretyczna:
    3.             
<head>
    (...)
        <style type="text/css">
        <!-- < ![CDATA[ -->
            selektor1 { cecha: wartość; cecha2: wartość2... }
            selektor2 { cecha: wartość; cecha2: wartość2... }
    (...)
        /* ]]> */
        </style>
    (...)
</head>
  3. Jakie mogą być selektory?

    4. Selektorem może być praktycznie dowolny znacznik, np. p (akapit), h1 (tytuł), td (komórka tabeli) i inne. To właśnie elementom, które znajdują się w kodzie źródłowym, pomiędzy tymi znacznikami, nadajemy atrybuty formatowania opisane w arkuszu.

  4. Jakie mogą być cechy i wartości?

    5. Cechami mogą być atrybuty HTML, np. color, font-size, align, margin, padding, border, background-color, etc. Wartością mogą być wartości liczbowe (np. 16px), kolory (np. red), czy też inne atrybuty HTML (np. align="center").
