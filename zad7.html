1. Na co pozwala styl lokalny?
    • nadanie formatowania konkretnemu pojedynczemu elementowi strony
    • określenie styli dla całego dokumentu
    • łatwe modyfikowanie wyglądu strony bez konieczności przeładowania całego dokumentu
    • przydatne przy tworzeniu stron witrynkowych, gdzie wygląd jest bardzo zależny od wielu elementów strony
  2. Składnia teoretyczna
    3. <style>
    p {
        color: red; /* Przykład użycia spacji niełamanej */
        font-size: 16px;
    }
</style>
  3. Co może być selektorem?

    4. Selektorem CSS może być dowolny znacznik HTML, a także różne kombinacje znaczników i klas.

  4. Co wipisujemy jako "cechę". Jakie jest znaczenie średników?

    5. Średnik (;) w CSS oznacza koniec selektora, a dwukropek (::) oznacza właściwość.

  5. Co wipisujemy jako "wartość" (w deklaracji stylu)?

    6. Wartością w CSS mogą być wartości liczbowe (np. 16px), kolory (np. red), czy też inne atrybuty HTML (np. align="center").
